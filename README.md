# 🌍 Multilingual Content Localizer

**AI-Powered Cultural & Linguistic Adaptation**

Author: Pranay M

## Overview

A Llama-based system that adapts content not just linguistically but also culturally for different markets worldwide.

## Features

- **Full Localization**: Language + cultural adaptation
- **Cultural Analysis**: Appropriateness checking, taboo detection
- **Marketing Adaptation**: Campaign localization with channel recommendations
- **UI Localization**: App/website string translation
- **Transcreation**: Creative slogan/tagline adaptation
- **Legal Localization**: Compliance-aware legal translation
- **Market Briefs**: Cultural and business insights
- **Quality Checking**: Accuracy, fluency, cultural scoring

## Supported Markets

US, UK, Spain, Mexico, France, Germany, Japan, China, Brazil, India, Saudi Arabia, South Korea

## Installation

```bash
ollama pull llama3.2
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
